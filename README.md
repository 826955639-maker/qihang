# 起航附中 · 补课班签到 / 排课 / 财务管理系统

一个面向初高中课外辅导机构的 Web 管理系统。本版已实现两大核心模块：

- **学生端签到**（防代签：本人确认 + Canvas 手写签名，签到即扣费，事务一致）
- **管理员端排课 / 财务**（两种排课模式 + 自动生成课次 + 教室冲突检测；收退款、多退少补、教师结算、总账分红）

> 采用响应式移动端优先设计，前端不依赖特定浏览器私有 API，便于后续向微信小程序迁移。

## 技术选型

| 层 | 选择 | 说明 |
|---|---|---|
| 后端 | Node.js + Express | 轻量、易迁移 |
| 数据库 | SQLite（better-sqlite3） | 真实数据库、同步事务，保证"签到-扣费"一致性 |
| 前端 | 原生 HTML/CSS/JS（响应式） | 无框架锁定，逻辑与 UI 分离，利于迁移小程序 |
| 签名 | Canvas 手写板 | 触屏 / 鼠标兼容，dataURL 持久化留痕 |

## 快速开始

```bash
npm install
npm run seed      # 写入海报种子数据（首次）；重置用 npm run reset
npm start         # 启动 http://localhost:3000
```

## 已实现功能

### 学生端（`/student.html`）
- **今日待签到**：列出本人已报名、今天的课次
- **手写签到**：确认本人姓名 → Canvas 手写签名 → 提交后记「正常签到」，自动从该课账户扣一节课费用（后端事务）
- **请假**：开课前 N 小时可请假（可配置），不扣费、不签名、不计课时
- **课表**：按年级展示，支持「今日 / 本周 / 按日期」视图，含进行中/已结束状态
- **个人账单**：每门课的上课/请假次数、累计充值/消耗、当前余额（低于阈值高亮预警）、历史签到记录与签名凭证

### 管理员端（`/admin.html`）
- **数据看板**：今日课程数、签到率、待补费学生数、本月营收、本月教师应付课时费
- **排课管理**：
  - 集训营模式（日期区间 + 固定节次 + 休息日 + 总讲次）
  - 常规周期模式（每周固定星期几 + 时间段 + 循环起止）
  - 保存后**自动生成每一次具体课次实例**供签到
  - **教室冲突检测**（同教室同时段重叠时拦截，可强制忽略）
  - 报名名单管理（一对一支持单独指定学生）、课次代录签到、停课/恢复
- **财务管理**：
  - 收款登记：预存充值 / 打包报名（按总课时自动折算单价）
  - 退款登记
  - **多退少补**：`应收 = Σ(正常签到次数 × 单价)`，`差额 = 已收 - 应收`
  - 教师课时费结算：按**实际有签到的课次** × 课时费，标记已付
  - 机构总账 / 分红：`可分红 = 总收入 − (教师课时费 + 其他成本)`，按负责人比例分配
  - 成本录入、时间段筛选
- **学生 / 教师管理**、**操作日志**（对账追责）、**系统设置**（旷课扣费策略、请假提前时长、改密、教室增删、分红比例）

## 数据模型

见 [`server/db.js`](server/db.js)：`students / teachers / classrooms / courses / session_instances / enrollments / student_accounts / transactions / attendance_records / audit_logs / partners / costs / teacher_settlements / settings`。

- 账户余额**按课程独立**管理（不同课单价不同）
- 签到扣费在一个 SQLite 事务内完成，避免"签到成功但扣费失败"

## 种子数据

按暑期招生海报录入（`server/seed.js`）：初一 / 初二 / 初三集训营课表 + 分班考，高一以「常规周期模式」演示课呈现。海报为招生物料不含内部定价，故**单价、课时费、分红比例为演示占位值**，管理员可在后台随时修改。

## 目录结构

```
server/
  index.js       Express 入口 + 登录
  db.js          SQLite 表结构
  schedule.js    课次自动生成 + 教室冲突检测
  auth.js        Token 鉴权（管理员密码 / 家长手机号）
  lib.js         账户、扣费、审计工具
  seed.js        海报种子数据
  routes/
    student.js   学生端接口（课表/签到/请假/账单）
    admin.js     管理端接口（排课/报名/签到/财务/看板/日志/设置）
public/
  index.html     登录（角色切换）
  student.html   学生端
  admin.html     管理端
  js/ css/        前端逻辑与样式
```
