# 《鸿鹄远征》拼贴风动画短片 · 制作规范

> 本文件是给 Claude Code 的完整制作说明。所有画面、节奏、配色、字体、动效、音频对齐规则都已定好，按本文件实现即可，不要自行改动风格。
> 比赛要求：MP4，≥1080p，2–5 分钟，≤500MB。本片目标 3:00。

## 1. 技术方案

- 框架：**Remotion**（React + TypeScript），所有画面用 React 组件 + SVG 绘制。
- 规格：1920×1080，30fps，总长 5400 帧（3:00）。
- 渲染：`npx remotion render HongHu out/honghu_yuanzheng.mp4 --codec=h264 --crf=20`
  - 预计体积 150–300MB，满足 ≤500MB。超出则把 crf 调到 23。
- 所有图形素材由代码生成（SVG 剪纸），**不使用任何网络图片或历史照片**，避免版权问题。唯一的外部图像素材是小鸿鹄官方形象（见第 5 节）。

## 2. 视觉风格：拼贴（Collage）

**一句话定义**：像一本用牛皮纸、旧报纸、彩纸剪贴出来的手账，每张纸片都有撕边、投影和轻微抖动，镜头像在桌面上俯拍定格动画。

**必须做到**

1. 底色永远是纸，不出现纯色平涂背景。
2. 每个元素都是"一张纸片"：有撕边或剪刀边、有硬投影、有轻微旋转。
3. 动画是"定格感"：纸片位移按 **两帧一更新（on twos，即 15fps 节奏）**，并叠加 ±1.5° 的随机微抖。
4. 全片叠一层纸纹 + 胶片颗粒。
5. 历史段（S1、S2）偏旧：降饱和、偏黄；现实段（S3 起）转暖、提亮。

**禁止**

- 不用渐变光效、发光粒子、3D、玻璃拟态等"科技风"手法。
- 不用徽派建筑、马头墙、水墨晕染等徽州元素。
- 不出现可辨认的真实人物面孔；人物一律是剪影剪纸。
- 不用任何受版权保护的图片、歌词、诗词原文。

## 4. 通用组件（`src/components/`）

| 组件 | 规格 |
| --- | --- |
| `PaperBG` | 牛皮纸底：底色 `kraft` + SVG `feTurbulence`（baseFrequency 0.9，numOctaves 3）纸纤维纹，透明度 18%；四角暗角 vignette 30%。 |
| `TornPaper` | 任意形状的纸片。边缘用随机多边形抖动生成撕边（每 8–12px 一个顶点，向内外随机偏移 2–5px，seed 固定保证每帧一致）。props：`color`、`width`、`height`、`rotate`、`seed`、`edge: 'torn' \| 'cut'`。 |
| `Shadow` | 所有纸片统一硬投影：`drop-shadow(6px 8px 0 shadow)`，不模糊。 |
| `Jitter` | 包裹任何纸片：每 2 帧随机一次 `rotate ±1.5°`、`translate ±1.5px`，seed 基于组件 id。 |
| `OnTwos` | 把动画进度按 2 帧取整：`Math.floor(frame/2)*2`，所有位移动画都要经过它。 |
| `DropIn` | 纸片入场：从上方 60px、旋转 −8° 落下，12 帧内到位，最后 4 帧轻微回弹（spring，damping 12）。 |
| `PeelOut` | 纸片出场：向右上翻起并移出，10 帧。 |
| `RedLine` | 长征路线红线：SVG path，`stroke=red`，宽 10px，`stroke-dasharray` 动画按进度画出；线条边缘加 1px 抖动模拟手绘马克笔。 |
| `Subtitle` | 字幕：底部居中，距底 72px；底板是一条 `newsprint` 色撕边纸条（左右留 32px），文字 `ink`。逐句出现，入场 `DropIn` 简化版（6 帧），出场直接切。 |
| `Grain` | 全片最顶层：每帧刷新的噪点，透明度 8%，`mix-blend-mode: multiply`。 |
| `Tape` | 半透明胶带：`#F3E3A0` 60% 透明度，矩形撕边，斜 ±15° 贴在纸片角上，用于"贴照片"的视觉。 |
| `StampText` | 印章式年份/数字：`red` 色，思源宋体，外加 4px 不规则方框，入场为"盖章"：scale 1.4→1，6 帧，伴随 `sfx/stamp.wav`。 |

## 5. 小鸿鹄

- 作者会把官方形象 PNG（透明底）放入 `public/xiaohonghu/`，命名：
  - `stand.png` 站立 · `fly.png` 飞行 · `look.png` 张望 · `happy.png` 开心（如只有一张，全部用 `stand.png`）
- **在拿到官方图之前**，用占位组件 `XiaoHongHuPlaceholder`：一只白色纸片剪成的大鸟侧影（椭圆身体 + 长颈 + 三角翅膀），翅膀尖用 `red`，旁边贴一张小纸条写"占位·待替换"。所有用到小鸿鹄的地方都通过 `<XiaoHongHu pose="fly" />` 调用，替换时只改这一个组件。
- 小鸿鹄同样当作"一张纸片"处理：加白色 6px 描边（像剪下来的贴纸）+ 硬投影 + `Jitter`。
- 动作（全部用变换实现，不需要逐帧动画）：
  - **飞行**：沿路径移动，身体上下浮动 ±12px（周期 20 帧），整体旋转跟随路径切线方向。
  - **扇翅**（仅当有 `fly.png`）：scaleY 在 1 与 0.85 之间切换，每 4 帧一次。
  - **落脚**：`DropIn` + 落地时 scaleY 0.9 压扁 3 帧再回弹。
  - **张望**：水平翻转 1 次，间隔 30 帧。
- 尺寸：常规 280px 高；S0 特写 520px 高；S7 肩头 360px 高。

**场景转场统一规则**：小鸿鹄从画面右侧飞入、横穿到左侧，它飞过的地方，新场景的纸面像被"翻页"一样从右向左盖过来（一张大 `TornPaper` 擦除遮罩），时长 20 帧，落在两个场景交界处（前 10 帧 + 后 10 帧）。

### S0 序·发问（0–450）

- 俯视桌面：`PaperBG` 上散放三张纸片——一张泛黄的旧地图（`newsprint`，上面用细线画出示意性的山川轮廓）、一张空白车票形纸条、一张贴着 `Tape` 的空相框纸。
- 帧 0–30：纸片依次 `DropIn`。
- 帧 40–90：小鸿鹄 `look` 姿态从左侧"走"入（每 6 帧前进一步，有落脚压扁），停在地图旁。
- 帧 100–160：小鸿鹄低头，用翅尖碰地图；地图中央出现一个红点，开始脉动（scale 1→1.3，周期 20 帧）。
- 帧 170–330：画面中央 `StampText` 风格的问句逐字出现：**鸿鹄一飞，能飞多远？**（思源宋体 72px，`ink`，每字间隔 6 帧，每字带"啪"一声 `sfx/type.wav`）。
- 帧 360–450：镜头推进（整体 scale 1→2.4），推入地图红点 → 过渡到 S1。

### S1 回望长征（450–1350）

- 背景：放大后的地图纸，历史滤镜生效。
- 主线：`RedLine` 从画面左下（标"于都"）向右上蜿蜒画出，全程 750 帧画完，路径示意即可，**不要求地理精确**，左下角小字标注"路线示意"。
- 沿红线依次"贴"出剪纸小场景（每个都是 `TornPaper` + 剪影，`DropIn` 入场，停留到被红线经过后缩小到 60% 留在路边）：

| 帧 | 剪纸场景 | 画法 |
| --- | --- | --- |
| 470 | 夜渡于都河 | 深蓝纸为夜空，三条 `river` 色波浪撕纸条为河，一串黑色剪影小人走在一条浮桥纸条上；桥上方 6 个 `gold` 三角火苗，每 3 帧随机缩放 0.9–1.1 闪烁 |
| 700 | 火把长队 | 一排 20 个小剪影从左向右前进（on twos），头顶火苗 |
| 900 | 江河 | 多条 `river` 色纸条层叠成河，旁边 `StampText` "近百条江河" |
| 1050 | 雪山 | 白色 `paper` 撕纸三角叠成雪山，剪影队伍沿山脊线向上 |
| 1200 | 草地 | `grass` 色锯齿纸条层层叠，小剪影相互搀扶（两个剪影靠在一起） |

- 数字印章（`StampText`，`red`）：帧 520 "1934"，帧 600 "86000+"，帧 800 "600余次战斗"，帧 1000 "40余座高山"，帧 1290 "1936 · 会师"。
- 帧 1290：红线到达终点，终点处三条短红线从三个方向汇聚到一点（会师），盖一个红星印章。
- 帧 1320–1350：转场到 S2。

### S2 工大的远征（1350–2100）

- 背景切为一张安徽省轮廓的示意剪纸（`newsprint`，简化外轮廓即可，不必精确），左上标"安徽"。
- `RedLine` 依次连接三个点，每到一个点 `StampText` 盖章并弹出一张"老照片"纸片（用 `Tape` 贴住，内容是剪纸画：简笔平房 / 山坡 / 城市楼群）：
  - 帧 1400：**1945 蚌埠黄庄** — 平房 + 一面小旗
  - 帧 1560：**淮南洞山** — 山坡 + 几间屋
  - 帧 1720：**合肥** — 楼群天际线，用 `indigo`
- 帧 1850–2000：三张老照片收拢叠成一摞，上面贴一条大纸条，思源宋体写：**工业报国**；下方再贴一条：**艰苦奋斗 · 自强不息**（每条 `DropIn`）。
- 帧 2040–2100：历史滤镜在转场中褪去，转场到 S3。

### S3 实验室与车间（2100–2850）

- 色调转暖，背景换成 `indigo` 底的方格纸（20px 网格线，`paper` 色 10% 透明度），像工程图纸。
- 画面中央一扇剪纸窗户，窗外是黑夜，窗内亮着 `gold` 色台灯光（一个扇形纸片）。右上角贴一个剪纸时钟，指针停在 2:00，秒针每 30 帧跳一格。
- 依次贴入元素（`DropIn`，错落 20 帧）：电路板纸片（绿底 + 金色线条）、一张写满公式的草稿纸（用波浪线代替文字）、一个齿轮（缓慢旋转，on twos）、一辆剪纸方程式赛车侧影。
- 帧 2400 左右：一只剪影手从画面下方伸入，拿起扳手拧齿轮（扳手旋转 3 次）。
- 小鸿鹄 `stand` 趴在桌边，随齿轮转动歪头 2 次。
- **口述卡片 #1**（帧 2600–2820）：画面右侧 `DropIn` 一张白色撕纸卡片，`Tape` 贴住，马善政字体写：
  > 我的长征路，是第 N 次重新跑通的程序。
  卡片右下角小字署名：`—— 某学院 某同学`（作者替换）。若 `voices/v1.wav` 存在则同步播放。

### S4 田野与课堂（2850–3600）

### S5 设计与创造（3600–4200）

### S6 接力（4200–5100）

- 背景：清晨天空，从 `indigo` 纸到 `gold` 纸的横向分层撕纸（5 层，不用渐变）。
- 帧 4200–4500：校园剪纸剪影从下往上逐层 `DropIn`：湖面（`river` 波纹纸条）、图书馆、教学楼、树。全部用 `indigo` 剪影 + `paper` 窗户小方块。只做概括性剪影，不必还原具体建筑。

## 7. 旁白与字幕（写入 `timeline.ts`）

旁白由作者自录或用 TTS 生成（推荐 edge-tts，音色 `zh-CN-YunxiNeural`，语速 `-10%`），逐句存为 `public/audio/narration/nXX.wav`。

**对齐规则**：下表"起始帧"是计划值；若对应 wav 存在，用 `getAudioDurationInSeconds` 读取真实时长，字幕持续到该句音频结束 + 6 帧；如果某句实际时长超出其场景，压缩该句之后的留白，不移动场景边界。字幕文本 = 旁白文本。

## 9. 实现顺序（Claude Code 按此执行）

1. 初始化 Remotion 项目，建好目录结构，写 `theme.ts`。
2. 实现第 4 节全部通用组件，做一个 `Playground` composition 把每个组件摆出来检查。
3. 实现 `XiaoHongHu`（含占位版本）。
4. 按 S0 → S7 顺序逐个实现场景，每完成一个场景渲染该段的静帧（`npx remotion still`，取场景中点帧）检查。
5. 接入字幕与音频对齐逻辑（第 7 节）。
6. 接入音乐与音效（第 8 节）。
7. 全片渲染，检查：时长 2:58–3:02、分辨率 1920×1080、体积 ≤500MB。
8. 输出 `out/honghu_yuanzheng.mp4`。
